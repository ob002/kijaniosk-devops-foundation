# DevOps Delivery Notes: KijaniKiosk

## 1. Flow
To ensure smooth flow, we are adopting a GitHub Flow workflow with small batch sizes and automated CI/CD pipelines to reduce manual bottlenecks.

## 2. Feedback
Every change goes through a Pull Request (PR) for immediate peer feedback. We will use cloud monitoring to alert the team if error rates spike.

## 3. Learning
We will conduct blameless post-mortems if deployments fail. This "Starter Kit" repository ensures new engineers understand the "why" behind our architecture.
